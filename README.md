## Как работает

Между двумя пк устанавливается tcp подключение, после чего запускается игра. Пк должны находиться в одной локальной сети.

## Управление

| Клавиша | Действие |
|---------|----------|
| `W`     | вверх    |
| `A`     | влево   |
| `S`     | вниз    |
| `D`     | вправо    |
| `Space` | выстрел |
